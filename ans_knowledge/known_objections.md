# ANS Known Objections

> **⚠️ This file should be completed by ANS, but the tool will still work without it.**
>
> The objections writer generates 15–20 objection-handling rows for the XLSX output. It uses this file to anchor its output in objections ANS actually encounters, rather than generating generic ones.
>
> Fill in real objections you hear repeatedly in sales conversations. The more specific and honest, the more useful the generated document. The agents will never fabricate — if this file is thin, the output will be more generic.

---

## How to fill this in

For each objection, provide:
- The surface objection (what they say)
- The underlying concern (what they actually mean)
- The response that has worked for you
- Any supporting evidence (customer story, spec, regulatory reference)
